# たまたま当たった？（tamatama-atari）

止まった時計がたまたま合っていた、羊に見えた岩の陰に本物の羊がいた――。短い話を読んで、その人が「知っていた」のか「たまたま当たった」のか（または「外れていた」のか）を選ぶ1日5問の学習ゲーム。知っていたでなければ、どの札が欠けたか（理由の札・当たりの札・運の札）も選ぶ。ゲティア問題（知識は、よい理由のある本当の信念？）の入り口に。

遊ぶ: <https://satou-aaaaa.github.io/tamatama-atari/>

- 話は日常の作り話です。考え方は次の資料を、短くやさしく言いかえたものです。
  - Edmund L. Gettier, 1963, "Is Justified True Belief Knowledge?", Analysis 23(6): 121–123（<https://doi.org/10.2307/3326922>）
  - Bertrand Russell, 1948, Human Knowledge: Its Scope and Limits（止まった時計の例）
  - Jonathan Jenkins Ichikawa and Matthias Steup, "The Analysis of Knowledge", Stanford Encyclopedia of Philosophy（<https://plato.stanford.edu/entries/knowledge-analysis/>）
- 3つの札は、よい理由があったか（理由）・信じたことが本当だったか（当たり）・理由と当たりが運でつながっていないか（運）です。哲学では「知っている」とは何かについて、いまも考えが分かれています。ゲームには、多くの人が同じ答えになる話だけを出しています。
